/*
PENJELASAN LATIHAN

1. rerata.cpp
Program diubah agar dapat menghitung rata-rata dari lima nilai.
Bagian yang perlu diperhatikan adalah input lima nilai, proses penjumlahan,
dan perhitungan rata-rata. Setelah diubah, catat bagian kode yang mengalami
perubahan dan berapa banyak tempat yang terpengaruh.

2. hello.cpp - Kesalahan tanda kutip
Tanda kutip penutup (") sengaja dihapus, kemudian program di-build kembali.
Compiler akan menampilkan pesan error karena sintaks pada program tidak benar.
Catat pesan error dan nomor barisnya. Setelah selesai, kembalikan kode seperti
semula.

3. hello.cpp - Menghapus iostream
Baris #include <iostream> dihapus kemudian program di-build kembali.
Jika program menggunakan cout atau cin, compiler akan mengalami error karena
library iostream tidak lagi disertakan. Error ini berbeda dari latihan nomor 2
karena penyebabnya adalah library yang dibutuhkan tidak tersedia.

4. rerata_awal.cpp - Tanpa -Wall dan -Wextra
Program di-build tanpa menggunakan opsi -Wall dan -Wextra.
Akibatnya, beberapa pesan warning dari compiler tidak ditampilkan.
Hal ini dapat merugikan karena warning dapat membantu menemukan kesalahan
atau potensi bug dalam program sejak awal.

KESIMPULAN:
Latihan ini bertujuan untuk memahami proses compile/build pada C++,
mengenali error dan warning, serta memahami pentingnya penggunaan
